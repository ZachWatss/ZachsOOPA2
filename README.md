Social Media Application

A Java-based desktop social media application developed as part of my Object-Oriented Programming coursework.

The project focuses on applying object-oriented programming principles to create a functional graphical user interface and simulate the core functionality of a social media platform.

Features
User interface for interacting with the application
User account functionality
Social media-style interactions
Multiple application screens
Navigation between different parts of the application
Object-oriented Java implementation
Event-driven GUI functionality
Technologies Used
Java
Java Swing
NetBeans
Apache Ant


Project Structure
